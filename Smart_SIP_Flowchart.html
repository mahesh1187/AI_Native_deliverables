Smart SIP Agent — System Flowchart

End-to-end data pipeline, AI backtesting engine, buy-signal generation, and live deployment flow for mutual fund dip-buying.

🔀 Pipeline Flow Diagram

8-stage system from fund selection to live deployment

1 INPUT STAGE

🏦 Select Mutual Fund Name

User selects a mutual fund scheme (e.g., HDFC Flexi Cap, Mirae Asset Large Cap) via the UI or CLI. The scheme code is resolved via AMFI/mfapi search API.

mfapi.in AMFI India Scheme Code Lookup User Input
2 DATA EXTRACTION

📂 Extract Monthly Portfolio Holdings

Fetch the fund's monthly portfolio disclosure from AMFI to identify the top equity holdings — stock names, quantities, % of AUM. This becomes the universe of stocks to track.

AMFI Portfolio API indian_mf_extractor.py Pandas DataFrame Monthly CRON
3 NAV DATA

📈 Collect MF NAV Data

Pull historical & live NAV for the selected scheme. Compute daily returns, drawdowns, rolling CAGR, and volatility metrics.

mfapi.in/mf/{id} NAV CSV CAGR / Returns
4 STOCK DATA

📊 Collect Stocks Data (1 Year)

For each top holding, fetch 1-year historical OHLCV plus real-time live prices via Yahoo Finance / NSE APIs. Build per-stock feature tables.

yfinance NSE India API OHLCV Live + Historical
5 AI / ML ENGINE

🤖 Fine-Tune AI Model & Perform Backtest

Train/fine-tune a model (XGBoost, LSTM, or LLM-based reasoning agent) on the combined feature set. Run historical backtests across 1-year window to measure strategy alpha, Sharpe ratio, and max drawdown vs. fixed SIP baseline.

XGBoost / LightGBM LSTM / Transformer LLM Reasoning Backtrader Scikit-learn Feature Engineering
6 SIGNAL GENERATION

🚨 Model Reasoning — Buy Signal Logic

When the model detects that top holdings are down significantly (e.g., ≥3% from recent peak), generate a BUY signal with confidence score & reasoning chain. The AI explains why the dip is an opportunity vs. a structural decline.

Buy Signal Confidence Score Chain-of-Thought Explainability (XAI) Dip Threshold Rules
7 TESTING & FINE-TUNING

🧪 Prepare Test Cases & Fine-Tune Model

Build a comprehensive test suite — edge cases (flash crash, low-vol drift, budget exceeded), historical replay tests, and synthetic scenarios. Use test results to retrain and improve model precision & recall for dip detection.

pytest MLflow Synthetic Data Precision / Recall Edge Cases
8 DEPLOYMENT

🚀 Deploy for Live Trading

Deploy the pipeline as a live service — scheduled NAV polling, real-time stock monitoring, automated signal dispatch (push notification / Telegram / email), and optional auto-execute via broker API (Zerodha Kite, Groww, etc.).

Docker AWS / GCP FastAPI Cron Scheduler Zerodha Kite API Telegram Bot

🧰 All Resources & Tools

Complete inventory of APIs, libraries, infrastructure, and services used across the pipeline

🌐 Data APIs & Sources

  • mfapi.in — Free NAV history, scheme search, fund metadata
  • AMFI India — Official NAV feed (NAVAll.txt) + portfolio disclosures
  • yfinance — Yahoo Finance API for stock OHLCV data
  • NSE India API — Live NSE stock quotes and indices
  • Alpha Vantage — Alternate stock data provider (API key)
  • Moneycontrol / Screener.in — Supplementary fundamental data

🐍 Python Libraries

  • pandas — Data wrangling, time-series manipulation
  • numpy — Numerical computing, array operations
  • requests — HTTP API calls
  • beautifulsoup4 — HTML parsing for web scraping
  • openpyxl — Excel file read/write
  • tabulate — Pretty-print data tables
  • schedule / APScheduler — Job scheduling
  • python-dotenv — Environment variable management

🧠 Machine Learning & AI

  • scikit-learn — ML pipelines, metrics, preprocessing
  • XGBoost / LightGBM — Gradient boosted tree models
  • TensorFlow / PyTorch — LSTM / Transformer deep learning
  • OpenAI / Google Gemini API — LLM-based reasoning agent
  • SHAP / LIME — Model explainability (XAI)
  • MLflow — Experiment tracking, model registry
  • LangChain / LlamaIndex — LLM orchestration framework

⏪ Backtesting & Strategy

  • Backtrader — Python backtesting framework
  • Zipline / QuantConnect — Alternate backtesting engines
  • TA-Lib / pandas-ta — Technical analysis indicators
  • pyfolio — Portfolio analytics & tear sheets
  • Custom feature engineering (RSI, MACD, drawdown, z-score)

🧪 Testing & Validation
